## 1. 设计原则

1. **一页讲清**：客户侧核心是「一个项目一张主页」。
2. **三分钟可用**：服务方注册 → 建项目 → 发出链接，路径极短。
3. **克制**：凡是 CRM / 财务 / 复杂权限，默认不做。
4. **付费钩子干净**：免费 1 个进行中项目；升级理由可解释、不锁已有数据。
5. **中文优先**：文案、空状态、示例数据均为中文。

---

## 2. 信息架构

```
ClientLink
├── 营销站（落地页 / 定价 / FAQ / 对比）
├── 服务方应用（需登录）
│   ├── 仪表盘（项目列表）
│   ├── 项目详情
│   │   ├── 概览（状态、客户、链接）
│   │   ├── 进度时间线
│   │   ├── 文件
│   │   ├── 留言
│   │   └── 设置（客户邮箱、归档、吊销链接）
│   ├── 账户 / 订阅
│   └── 设置（资料、通知偏好）
└── 客户端门户（magic link，无密码）
    └── 项目一页通（进度 + 文件 + 留言 + 待办）
```

导航原则：服务方侧不超过两级主导航；客户侧无复杂导航，单页+锚点或简单 Tab。

## 3. 角色与权限

### 3.1 角色

| 角色 | 身份 | 认证方式 |
|------|------|----------|
| Owner（服务方） | 设计师/开发/顾问本人 | Email + Magic link 或 OAuth（可选 Google）；会话登录 |
| Client（客户） | 项目外部客户 | 仅项目级 Magic link（token）；可设定过期与吊销 |
| 系统 | 计费与限额 | Stripe/Lemon/国内支付回调（见开发方案） |

MVP **不设** Member / Admin 多成员；一人一账号。

### 3.2 权限矩阵（MVP）

| 动作 | Owner | Client |
|------|-------|--------|
| 创建/归档项目 | ✓ | ✗ |
| 编辑项目状态与进度条目 | ✓ | ✗ |
| 查看进度 | ✓ | ✓ |
| 上传文件 | ✓ | ✓ |
| 删除文件 | ✓（全部） | ✓（仅自己上传，可选） |
| 留言 | ✓ | ✓ |
| 查看客户邮箱与计费 | ✓ | ✗ |
| 复制/吊销 magic link | ✓ | ✗ |
| 升级订阅 | ✓ | ✗ |

### 3.3 Magic link 规则

- 链接含不可猜测 token；绑定 `project_id`。
- 支持「重新生成」（旧链失效）。
- 可选过期时间：7 / 30 / 90 天 / 永不过期（Pro 可开放更长）。
- 打开链接不创建全局账号；仅项目上下文。

## 4. 核心页面说明

### 4.1 落地页

- 价值主张、演示视觉、定价、FAQ、CTA。
- 次要：GitHub（Lt-wei）链接。

### 4.2 仪表盘

- 卡片/列表：项目名、客户名、状态、最后活动时间。
- 主按钮：新建项目。
- 免费用户已有 1 个进行中时，新建 → 升级引导模态框。

### 4.3 新建项目

字段（MVP）：项目名称、客户显示名、客户邮箱（用于发链）、初始状态。  
提交后进入项目详情并突出「复制客户链接」。

### 4.4 项目详情（服务方）

- **概览**：状态徽章、客户链接、一键复制、最后客户访问时间（若可统计）。
- **进度**：时间线条目（标题、时间、可见性=客户可见）。
- **文件**：列表（名、大小、上传者、时间）；上传组件。
- **留言**：按时间倒序；区分 Owner / Client 样式。
- **设置**：归档、吊销链接、删除项目（二次确认）。

### 4.5 客户一页通

自上而下：

1. 项目名 + 服务方显示名  
2. 当前状态（大号、可读）  
3. 待办提示（若有「请上传 LOGO」类 Owner 备注）  
4. 最近进度（3–10 条）  
5. 文件区（下载/上传）  
6. 留言区  

空状态文案友好：「还没有文件，把需求资料传给我吧。」

### 4.6 账户 / 订阅页

- 当前方案：免费 or Pro  
- 进行中项目数 / 限额  
- 升级按钮：月付 ¥68 / 年付 ¥688  
- 发票信息可后期再做；MVP 能显示「已订阅」即可

## 5. MVP 范围（Must）

| 模块 | 包含 |
|------|------|
| 账号 | 邮箱登录（magic link 登录服务方亦可） |
| 项目 | CRUD、状态枚举、归档、进行中计数 |
| 客户链接 | 生成、复制、吊销、访问项目页 |
| 进度 | 增删改查简易时间线 |
| 文件 | 上传、列表、下载；单文件大小上限（如 20MB） |
| 留言 | 发送与列表；基础垃圾防刷（rate limit） |
| 限额 | 免费 1 进行中；Pro 更高或无限（如 50） |
| 营销页 | 定价与注册入口 |

### 状态枚举建议（可调）

`草稿筹备` | `进行中` | `等待客户` | `待确认` | `已完成` | `已归档`

「进行中」定义：非「已完成/已归档」的项目计入免费限额。

## 6. 明确不做（MVP 与近半年默认 No）

- 合同、电子签、报价单、发票、收款账户托管  
- 销售管道、线索、邮件营销  
- 多成员、角色权限、部门  
- 甘特图、工时表、复杂任务依赖  
- 客户全局账号体系与跨项目客户 CRM  
- 白标整站 / 任意自定义域名（可作为 Pro+ 后期）  
- 原生 App  
- AI 自动写进度（除非验证强需求）  
- 企业 SSO、私有化部署（可商机另议）

任何「做一点吧」的需求，进冰盒，需同时满足：服务付费转化或强留存，且不破坏「一页通」心智。

## 7. 用户流程

### 7.1 服务方：首次成功路径

```
访问落地页 → 注册/登录 → 引导创建首个项目
→ 填写名称与客户邮箱 → 生成 magic link
→ 复制并发给客户（微信/邮件）→ 在详情页添加一条进度
→ 上传文件 → （可选）等客户留言
```

成功标准：15 分钟内完成上述路径；有「已复制链接」的明确反馈。

### 7.2 客户：首次访问

```
收到链接 → 浏览器打开 → 看到项目一页通
→ 阅读状态与进度 → 上传文件或留言 → 关闭
```

无注册墙。失效链接显示「链接已失效，请联系对方重新发送」。

### 7.3 升级 Pro

```
仪表盘点击新建 → 触发限额 → 说明 Pro 权益
→ 选择月/年 → 支付 → 回跳解锁新建
```

已有项目与文件保持可访问；不付费不删数据。

### 7.4 归档释放名额

```
项目设为已完成/归档 → 进行中计数 -1 → 免费用户可再开新项目
```

引导文案：归档旧项目也可继续只读给客户（产品决策：归档后客户只读，不占进行中名额）。

## 8. 关键与文案要点

- 主色干净、偏专业服务（避免过度花哨）；Tailwind 组件保持一致性。
- 按钮文案用动词：复制客户链接、上传文件、标记为等待客户。
- 错误可恢复：网络失败可重试；上传失败保留表单。
- 移动端：客户页必须友好（大量客户用手机看微信里的链接）。

---

## 9. 非功能需求（产品侧）

| 项 | 要求 |
|----|------|
| 性能 | 客户页首屏可感知加载快（目标：常见网络下数秒内可用） |
| 安全 | 链接不可枚举；存储权限按项目隔离；基础 XSS 防护 |
| 可用性 | 关键路径有空状态与加载态 |
| 合规 | 隐私政策与用户协议链接放页脚；文件仅用于交付协作说明清楚 |
