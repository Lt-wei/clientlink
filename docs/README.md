## 项目一句话

**ClientLink（客户一页通）** 是面向设计师、独立开发者、顾问与小工作室的轻量客户门户：客户通过 magic link 查看进度、上传文件、留言沟通——不做重型 CRM，目标是**最快盈利**。

## 阅读顺序建议

1. **先看用户分析**：确认「谁会付钱、为什么付钱」。
2. **再看产品调研**：明确我们不跟谁正面硬刚、差异化在哪。
3. **对照产品设计**：MVP 只做能支撑定价的最小闭环。
4. **按开发方案排期**：2–4 周内上线可收费版本。
5. **用营销方案起量**：发布日前后 30 天动作清单可直接执行。

## 当前阶段结论（给决策用）

- **可做**：轻量门户 + magic link + 文件/留言/进度，技术路径成熟，成本可控。
- **该砍**：合同、报价、发票、复杂 CRM、团队权限体系——全部放到 Pro 之后或永不做。
- **盈利路径**：免费锁 1 个项目 → 有第二项目或需要品牌感时升 Pro；年付折扣提高 LTV。
- **风险**：同类「客户端页」工具多、同质化快；必须用「中文体验 + 极简 + 价格」打穿垂直场景。
