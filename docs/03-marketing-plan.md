## 1. 营销目标（服务最快盈利）

| 阶段 | 时间 | 目标（可执行、可统计） |
|------|------|------------------------|
| 预热 | 上线前 7 天 | 等待列表或兴趣名单 80–150 人；收集 5 个种子用户承诺试用 |
| 发布 | Day 0–7 | 注册 ≥ 100；至少 30 人创建项目；首批付费 3–8 人 |
| 稳定 | Day 8–30 | 付费用户到 15–30；沉淀 5 条真实案例话术；周内容不断更 |

数字为**内部努力目标**，非对外承诺；以付费与留存为准绳。

## 2. 定位话术

### 2.1 一句话

**客户一页通：magic link 看进度、传文件、留言——专为设计师和独立开发者，不做重 CRM。**

### 2.2 30 秒电梯稿

> 你有没有为了找客户上周发的那版稿，把微信翻到手软？ClientLink 给你和客户一个固定链接：进度、文件、留言都在一页。客户不用注册，点 magic link 就能进。免费先跑 1 个项目，多个项目再 ¥68/月。我们不是 HoneyBook，我们只做客户门户。

### 2.3 差异化三句（可轮换）

1. 不是 CRM，是客户门户。
2. 客户零密码，你零席位焦虑。
3. 从微信地狱毕业，不用上企业套件。

### 2.4 异议处理

| 客户说 | 回应 |
|--------|------|
| 我用微信就行 | 微信继续聊；一页通只存进度和文件，找得到、理得清 |
| 有飞书/Notion | 那些更适合团队内部；客户往往不想开账号，magic link 更友好 |
| 怎么不收款/合同 | 刻意不做；你用现有收款工具，我们把交付沟通做好 |
| 太便宜会不会跑路 | 技术栈透明（Next/Supabase/Vercel），成本结构健康；年付更省 |

## 3. 渠道策略

### 3.1 主渠道（投入 70% 精力）

| 渠道 | 内容形式 | 频率 | KPI |
|------|----------|------|-----|
| 小红书 | 对比截图、操作短视频（&lt;60s）、设计师日常痛点 | 每周 3–5 | 主页访问、注册 UTM |
| 即刻 | Build in public、诚实对比竞品、求助种子用户 | 每周 2–4 | 评论质量、加好友/试用 |
| X / 推特中文 | 线程：从 0 做 ClientLink；演示 GIF | 每周 2–3 | 点击落地页 |
| 垂直微信群 | 提供体验码，不硬广；先回答别人问题 | 有问必答 | 进群试用数 |

### 3.2 次渠道（投入 20%）

- 少数派 / 掘金 / v2ex：一篇深度「为什么不做 CRM」经验文（发布后第 2 周）。
- Product Hunt：若有英文 landing，可冲一天；中文用户仍靠国内渠道转化。
- SEO：官网博客「设计师如何给客户同步进度」等长尾（第 2 个月再加大）。

### 3.3 暂缓（投入 ≤10% 或 0）

- 信息流广告、KOL 大额投放：等付费单元经济验证后再说。
- 线下沙龙：费时，除非顺路。

## 4. 发布节奏

### 4.1 上线前 7 天

| Day | 动作 |
|-----|------|
| -7 | 落地页上线（价值主张+演示图+等待列表/提前注册）；同步 GitHub Lt-wei 仓库 README 指向产品 |
| -5 | 即刻+X 预告：「下周日发布客户一页通」；征集「最烦客户沟通的一件事」 |
| -3 | 小红书发痛点笔记（不带强链或带等待列表）；私信 10 个设计师朋友邀内测 |
| -1 | 准备发布素材包：3 张图、1 个 45s 视频、FAQ、定价说明 |
| 0 | 全渠道同一话术发布；置顶 Demo 项目体验链接 |

### 4.2 发布周（Day 0–7）

- 每天回复所有评论与私信（转化率最高的时段）。
- 每天记录：注册、创建项目、magic link 打开、付费。
- Day 3 发「72 小时数据与踩坑」透明帖（建立信任）。
- Day 7 发周复盘 + 下一周内容预告。

### 4.3 Day 8–30

- 内容栏目固定（见第 6 节选题）。
- 每周邀请 2 名付费/深度用户做 15 分钟通话，换季卡或延长 Pro。
- 若转化低：先改拦截文案与引导，不先加功能。

## 5. 前 30 天获客执行清单

### 第 1 周：曝光与激活

- [ ] 发布帖在小红书/即刻/X 各至少 1 条主帖 + 2 条跟进
- [ ] 种子用户 10 人一对一引导完成「创建项目→发送链接」
- [ ] 官网加 UTM：`?utm_source=xiaohongshu` 等
- [ ] 准备 1 个「演示用假项目」（设计改稿场景）供访客只读体验

### 第 2 周：信任与首单

- [ ] 发出 3 条用户原话（匿名也可）社交证明
- [ ] 针对「第二项目升级」优化 Paywall 文案
- [ ] 年付促销：早鸟年付 ¥588（限前 20 名，可选，避免长期贱卖）
- [ ] 深度文发布 1 篇

### 第 3 周：案例与推荐

- [ ] 产出 2 个图文案例：「设计师张三如何少回 20 条微信」
- [ ] 推出「推荐送 1 个月 Pro」（自建或用 Affonso 等简易方案，可先手工发码）
- [ ] 设计师社群 AMA 或直播演示 30 分钟

### 第 4 周：复盘与固化

- [ ] 统计渠道注册与付费归因，砍掉 0 转化渠道
- [ ] 沉淀官网 FAQ 与对比页（vs 微信、vs HoneyBook）
- [ ] 制定第 2 个月内容日历（保持同频，不烧尽）

## 6. 内容选题库（可直接排期）

### 痛点类

1. 客户说「文件发过了」你却找不到：我怎么用一页通结束这场拉锯
2. 独立设计师的进度同步：别再只发「在做了」
3. 顾问交付的作业提交区，比微信靠谱在哪

### 演示类

4. 45 秒：从创建项目到客户打开 magic link
5. 客户视角走查：她看到什么、能点什么
6. 免费用户如何升级到第 2 个项目（诚实演示 Paywall）

### 对比类

7. ClientLink vs 微信网盘：不是替代，是分工
8. 为什么我不做合同和 CRM（产品哲学）
9. 海外工具月费太贵时，中国自由职业者的轻量选项

### Build in public

10. 技术栈为什么选 Next.js + Supabase + Vercel
11. 本周付费转化数据（可模糊为区间）与下一周实验
12. 用户要合同功能，我为什么拒绝

### SEO / 长文（隔周）

13. 自由职业者客户沟通清单（可下载/可复制）
14. 设计工作室小型项目的文件命名与版本约定
15. Magic link 安全吗？我们怎么做过期与吊销

## 7. 落地页与转化结构

建议单页模块顺序：

1. 标题 + 副标题（定位话术）
2. 产品截图 / GIF（客户页为主视觉）
3. 三个卖点图标：进度、文件、留言
4. 定价（免费 / Pro 月 / Pro 年）
5. 「不是 CRM」短对比表
6. FAQ
7. CTA：免费开始 / GitHub（Lt-wei）可选

CTA 主按钮始终指向注册或 Demo，次按钮才是「看文档」。

## 8. 预算建议（极省）

| 项 | 预算 |
|----|------|
| 域名 + Vercel + Supabase 免费档 | 低，按官方免费额 |
| 设计素材 / 剪辑 | 自制 |
| 早鸟折扣成本 | 用时间换现金，严控名额 |
| 付费广告 | 第 1 个月 **0** |

把「时间」当主要预算：每天固定 60–90 分钟内容与回复。

---

## 9. 指标看板（每周五看）

- 新注册、激活（建项目）、客户链接打开率
- 免费 → Pro 转化率、月付 vs 年付占比
- 渠道来源 Top3
- 退订原因（若有）短记录
- 内容：每条主帖的点击与注册（能追就追）

---

## 10. 结论

营销不靠砸钱，靠 **尖锐定位 + 高频真实演示 + 第二项目付费钩子**。前 30 天胜利条件不是「爆」，而是：**有稳定内容节奏、有首批真金白银付费、知道谁在付钱**。
