## 1. 调研目的

- 看清「客户协作 / 客户门户 / 工作室操作系统」赛道里，谁在卖什么、卖给谁。
- 找出 ClientLink 可防守的差异化，避免做成「又一个 mini-CRM」。
- 识别市场机会与主要风险，服务「最快盈利」目标。

说明：本文不做编造的精确市场规模数字，以定性格局与可验证产品差异为主。

---

## 2. 赛道切分

| 类型 | 代表 | 用户买的是什么 |
|------|------|----------------|
| 创意服务操作系统 | HoneyBook、Dubsado | 询盘→报价→合同→收款→项目 |
| 全功能工作室/Agency 套件 | Plutio、多种 Agency OS | 项目+任务+CRM+发票+客户门户 |
| 客户端门户 / 协作层 | Copilot、部分 Notion 模板、自建页 | 给客户一个「家」，不一定管销售 |
| 开源 / 模板商用 | AgencyPro 等 | 可二次开发的后台+门户骨架 |
| 通用协作 | 飞书、Notion、微信+网盘 | 免费或已有，但非为「对外客户」设计 |

ClientLink 定位落在 **「客户端门户 / 协作层」**：只解决交付过程中的透明与文件留言，不碰销售漏斗。

---

## 3. 竞品对比

### 3.1 HoneyBook

| 维度 | 情况 |
|------|------|
| 强项 | 报价、合同、收款、工作流成熟；北美婚礼/创意服务心智强 |
| 弱项 | 偏贵；学习成本高；中文与国内支付弱；对中国独立从业者过重 |
| 对 ClientLink | **不要学它的广度**；可学「客户体验专业感」与邮件节点 |

### 3.2 Dubsado

| 维度 | 情况 |
|------|------|
| 强项 | 表单、流程自动化、品牌化客户体验细 |
| 弱项 | 配置复杂；同样偏欧美定价与场景 |
| 对 ClientLink | 自动化可后期做「轻量模板」，MVP 不做流程引擎 |

### 3.3 Plutio

| 维度 | 情况 |
|------|------|
| 强项 | All-in-one：项目、任务、CRM、提案、发票、门户 |
| 弱项 | 功能多 → 空置率高；小用户「只用到 10%」仍月付不安 |
| 对 ClientLink | 话术上可直接对比：「你不需要 All-in-one，只需要客户看懂进度」 |

### 3.4 Copilot（client portal 向产品）

| 维度 | 情况 |
|------|------|
| 强项 | 强调客户门户、消息、文件、品牌化；更贴近「门户」而非全 CRM |
| 弱项 | 定价与市场仍偏海外；功能集会逐渐变重 |
| 对 ClientLink | **最近似竞品方向**；差异靠：更窄、更快、人民币定价、中文体验、magic link 极简登录 |

### 3.5 AgencyPro（及同类模板/开源后台）

| 维度 | 情况 |
|------|------|
| 强项 | 可自托管、可改代码；适合会开发的 Agency |
| 弱项 | 要自己部署维护；非技术设计师用不了；不是「打开即用 SaaS」 |
| 对 ClientLink | 我们卖托管与省心；开源爱好者不是首要付费人 |

### 3.6 替代品（真正抢时间的对手）

- **微信群 + 网盘 + 腾讯文档**：零学习成本，默认选项。
- **Notion 对外分享页**：灵活，但权限、文件、客户「我该看哪」体验一般。
- **飞书/钉钉外部协作**：企业向，个人顾问与设计师不一定愿意拉客户进组织。

> 结论：最大对手不是 HoneyBook，而是 **「凑合用微信」**。产品与文案必须证明：多一个链接，每周少 30 分钟纠缠。

## 5. 差异化策略

### 5.1 我们坚持的差异

1. **只做客户一页通**：进度 + 文件 + 留言；一句话能讲清。
2. **Magic link 优先**：客户零注册心智；服务方也不管客户密码。
3. **中文场景与定价**：¥68/月，免费 1 项目，符合国内独立从业者支付习惯。
4. **最快盈利导向的克制**：功能少是卖点；官网写「我们不是 CRM」。

### 5.2 可感知的产品锚点

- 创建项目 → 复制客户链接：主路径少于 5 次点击。
- 客户打开即见：当前状态、最近文件、待办、留言框。
- 免费层清晰限制：进行中项目 = 1；升级理由不耍流氓（不突然锁文件）。

### 5.3 不作为早期差异的点

- AI 写周报、自动合同、复杂甘特图——同质化快且拖交付。
- 开源协议本身——可后期开源部分，不作为首年商业核心。

## 6. 市场机会（定性）

1. **供给缺口**：海外工具贵且重；国内「项目协作」多对内，少「对外客户只读+可传文件」的轻产品。
2. **人群变大**：设计外包、独立开发、知识顾问增多，多人「一人公司」同时服务多个客户。
3. **微信疲劳**：客户与服务方都对聊天记录找文件有体感痛，教育成本低于 5 年前。
4. **付费验证窗口短**：轻量工具若 2–4 周能上线收费，可用真实转化率指导是否加功能，而不是先做大而全。

## 7. 风险与应对

| 风险 | 可能性 | 影响 | 应对 |
|------|--------|------|------|
| 同质化（谁都能做个门户） | 高 | 中 | 速度+垂直文案+口碑案例；深耕设计师/独立开发话术 |
| 用户停留在免费 1 项目 | 中 | 高 | 强化第二项目拦截；Pro 增加品牌色/自定义域名等「体面」权益 |
| 微信习惯无法撼动 | 中 | 高 | 定位为「微信讨论 + 一页通存档」，非取代微信 |
| 竞品降价或出中文版 | 低-中 | 中 | 保持更窄；做本地支付与模板（设计交付、开发交付） |
| 文件与安全事故 | 低 | 极高 | Supabase 存储权限、magic link 过期/吊销、基础审计 |
| 范围蔓延做成 CRM | 高（内部） | 高 | 用《04》不做清单约束；新需求进冰盒 |

## 8. 定位陈述（对外可用）

> ClientLink（客户一页通）是给设计师、独立开发者和顾问的轻量客户门户。客户通过 magic link 查看进度、上传文件、留言反馈。我们不是 CRM，不帮你找客户，只帮你把正在服务的客户沟通变清楚——免费可先跑 1 个项目，Pro 每月 ¥68。

## 9. 调研结论 → 行动

| 决策 | 内容 |
|------|------|
| 做 | 门户 MVP、中文官网、人民币订阅、公开对比页（vs 微信 / vs 重工具） |
| 不做 | 合同、发票、管道、多角色复杂 ACL |
| 盯 | Copilot 类产品的门户功能演变；国内是否出现同价位竞品 |
| 验证 | 上线 30 天内：付费转化、周活项目、NPS/口头推荐 |
