## 1. 分析目标

回答四个问题，支撑「最快盈利」决策：

1. 谁最可能在 7 天内掏钱？
2. 他们现在怎么跟客户协作？痛在哪？
3. 什么功能足以让他们从免费升 Pro？
4. 在哪里能低成本找到这些人？

---

## 2. 核心用户画像

### 2.1 主画像 A：独立设计师 / 品牌设计师

| 维度 | 描述 |
|------|------|
| 身份 | 自由职业或 1–3 人小工作室，接品牌、海报、包装、落地页视觉 |
| 客户量 | 同时进行 2–5 个项目；客户多为中小商家、创始人 |
| 工具现状 | 微信传图 + 网盘 + 飞书/Notion 文档混用；无固定「客户门户」 |
| 时间敏感 | 高——改稿、确认、催反馈占大量沟通时间 |
| 付费信号 | 愿意为「少被微信轰炸、客户自己能看进度」付小额月费 |

**典型一天**：早上看微信未读 → 找上周发的那版稿 → 再问客户「定哪一版」→ 客户说找不到链接。

### 2.2 主画像 B：独立开发 / 技术顾问

| 维度 | 描述 |
|------|------|
| 身份 | 接小程序、网站、自动化脚本、咨询交付的个人或二人组 |
| 客户量 | 1–4 个并行交付；常有「等客户提供素材/账号」的阻塞 |
| 工具现状 | GitHub / Linear 自己用，但不会给客户开账号；进度用周报邮件或微信 |
| 痛点 | 客户反复问「做到哪了」；素材散落在聊天记录 |
| 付费信号 | 需要一个「只给客户看、不暴露内部看板」的外部门户 |

### 2.3 主画像 C：顾问 / 教练 / 服务型自由职业

| 维度 | 描述 |
|------|------|
| 身份 | 商业顾问、增长顾问、职业教练、合规/财务兼职顾问 |
| 协作物 | 问卷、诊断报告、行动清单、录音纪要、作业提交 |
| 痛点 | 客户忘交作业、找不到上次材料；自己也不想维护重 CRM |
| 付费信号 | 要「一个链接搞定交付与跟进」，而不是销售漏斗工具 |

### 2.4 次要画像（先观察，不优先获客）

- 5–15 人小型 Agency：需要席位、权限、报价合同 → **不是 MVP 目标**，会拖慢盈利。
- 纯企业内部项目组：采购与合规重 → 不碰。

## 3. 典型使用场景（Jobs to be Done）

### 场景 1：项目启动

服务方创建项目 → 填客户邮箱 → 系统发 magic link → 客户点开看到「欢迎页 + 待办（传 LOGO、填需求）」→ 服务方少打一通电话。

### 场景 2：改稿与确认

服务方更新进度状态（设计中 / 待确认 / 已确认）并上传最新稿 → 客户在同一页留言「第二页标题改短一点」并回传参考图 → 历史留言可追溯。

### 场景 3：催素材

服务方标记「阻塞：等客户」→ 客户打开链接看到醒目待办 → 上传文件后状态自动或手动变为「素材已收」→ 减少「你发了吗 / 我发了啊」的拉锯。

### 场景 4：结项与归档

项目标为完成 → 客户仍可只读访问终稿与留言记录 → 服务方腾出「进行中」名额（免费用户尤其敏感）。

### 场景 5：第二项目触发付费

免费用户第 2 个进行中项目被拦住 → 升级 Pro → **这是核心变现钩子**。

## 4. 痛点清单（按严重程度）

| 优先级 | 痛点 | 现状代价 | ClientLink 如何解 |
|--------|------|----------|-------------------|
| P0 | 沟通散落在微信，找不到历史与文件 | 每周浪费数小时翻聊天 | 项目一页通：进度+文件+留言同页 |
| P0 | 客户反复问进度 | 打断深度工作 | 客户自助查看状态时间线 |
| P1 | 不敢给客户开内部工具账号 | 要么过度暴露，要么零透明 | Magic link，无密码、无席位概念 |
| P1 | 素材版本混乱 | 改错版、重做 | 文件列表 + 上传时间 + 简单备注 |
| P2 | 工具太贵或太重（HoneyBook 等） | 学不会 / 用不起 / 功能浪费 | 中文、极简、低价、只做门户 |
| P2 | 看起来不专业 | 丢单或议价被动 | 干净的客户页、可带项目名与品牌色（Pro） |

**非痛点（不要当卖点）**：复杂销售管道、合同电子签、自动记账——用户说「有更好」，但不会为 MVP 付钱。

## 5. 付费意愿与定价契合度

### 5.1 定价回顾

- **免费**：1 个进行中项目（足够试用闭环）
- **Pro**：¥68/月 或 ¥688/年（约 10 个月年付）

### 5.2 意愿判断（定性）

- ¥68/月对独立接单者 ≈ 一单设计小费的零头，或少开一次会的时间价值 → **价格敏感度低**。
- 触发升级的真实时刻：
  1. 同时接第 2 个客户；
  2. 想去掉「Free」感、自定义品牌；
  3. 需要更多存储/文件数量（可作为后续 Pro 权益）。
- 年付 ¥688：用「送 2 个月」话术；适合已验证工作流、怕忘续费的人。

### 5.3 不愿付费的人

- 只用微信且拒绝任何新链接的客户群体（服务方也迁就）→ 教育成本高，暂不强推。
- 需要合同+收款+CRM 一体的人 → 引导去竞品，避免产品膨胀。

### 5.4 付费转化假设（供内部跟踪，非对外宣传）

- 注册 → 创建首个项目：高（产品本身引导）。
- 免费 → Pro：看「第二项目」拦截文案与时机；目标做成「阻塞时一键升」而非后台找订阅页。

## 6. 获客入口（哪里找这些人）

### 6.1 高匹配、低成本

| 入口 | 做法 | 理由 |
|------|------|------|
| 即刻 / 即友圈子 | 发「我做了个给客户看进度的一页通」实操帖 | 独立开发者与设计师密度高 |
| 小红书 | 前后对比：微信地狱 vs 一页通；短视频演示 magic link | 设计师内容消费强 |
| X (Twitter) 中文圈 | Build in public：GitHub Lt-wei + 周进展 | 技术独立开发者 |
| 设计师微信群 / 知识星球 | 提供 1 个月 Pro 兑换码换真实反馈 | 信任传递快 |
| v2ex / 少数派（视内容调性） | 经验帖：「我不做 CRM，只做客户门户」 | 理性用户，转化慢但质量高 |

### 6.2 中匹配、可试验

- Product Hunt / 即刻「产品发布」：偏品牌曝光，首日要英文+中文材料。
- 大学设计课讲师、训练营：批量学生用户，付费少，但口碑与案例多。

### 6.3 暂缓

- 百度/谷歌竞价：CAC 高，早期不适合。
- 大客户 BD：销售周期长，违背最快盈利。

## 7. 用户访谈提纲（可直接用）

1. 你同时进行几个客户项目？现在文件和进度放哪？
2. 上周有没有因为「找不到某版文件/某条反馈」返工？
3. 如果只给你一个客户链接，你最希望上面有哪三样？
4. 你用过 HoneyBook / 飞书客户群 / Notion 对外页吗？哪里不爽？
5. ¥68/月换「无限进行中项目 + 基础品牌」，你会不会订？卡点是什么？

建议：上线前访谈 8–10 人（画像 A/B 为主），上线后每两周回访付费用户 2 人。

## 8. 结论与产品含义

| 结论 | 对产品的要求 |
|------|----------------|
| 钱在「第二项目」和「少聊天翻记录」 | MVP 必须稳：magic link、进度、文件、留言 |
| 用户怕重工具 | 注册到发出客户链接 &lt; 3 分钟 |
| 中文独立从业者是滩头 | 文案、支付（人民币）、示例项目都要中文优先 |
| 不做 CRM 是卖点不是缺陷 | 官网与话术明确「我们不是 CRM」 |
